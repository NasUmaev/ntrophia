# NTrophia

Локальный MVP для личной коллекции достижений. Сервер и установка не нужны.

## Итерация 1 — надёжная основа

- Создание коллекций и переключение между ними.
- Удаление пустых коллекций и удаление коллекций с переносом трофеев в другую.
- Создание трофеев с названием, описанием, редкостью и коллекцией.
- Редактирование названия, описания, редкости и коллекции без сброса даты получения.
- Четыре редкости: платина, золото, серебро и бронза.
- Получение трофея с автоматической датой и возможность снять отметку.
- Удаление трофеев с подтверждением.
- Общий прогресс, счётчики и фильтры по редкости.
- Тёмная адаптивная тема.
- Сохранение данных в `localStorage` браузера.
- Экспорт всех данных в JSON и импорт с проверкой и подтверждением замены.

Всё приложение находится в `index.html`: HTML, CSS и JavaScript, без внешних зависимостей.

## Запуск на macOS

1. Откройте `index.html` двойным щелчком или перетащите его в Safari или Chrome.
2. Создайте коллекцию и добавляйте в неё трофеи.
3. Нажмите «Отметить», когда получите трофей. Дата проставится автоматически.

Данные сохраняются в `localStorage` текущего браузера на этом устройстве. Используется прежний ключ MVP — `nasik-trophies-v1`. Переименование приложения не меняет сохранения. Чтобы сохранить доступ к существующим данным, обновляйте HTML по прежнему пути и открывайте его в том же браузере. Для переноса между браузерами или путями используйте экспорт и импорт.

## Резервная копия

Нажмите «Экспорт JSON» и сохраните файл. Он содержит версию формата, дату экспорта, коллекции, трофеи, даты получения и выбранные фильтры.

Для восстановления нажмите «Импорт JSON», выберите файл и подтвердите полную замену текущих данных. Перед импортом полезно экспортировать текущее состояние: импорт заменяет данные, а не объединяет их. Отмена подтверждения и некорректный файл оставляют текущее сохранение без изменений.

Принимается собственный экспорт версии 1 и исходный объект сохранения MVP. Проверяются обязательные поля, типы, длины текстов, даты, четыре редкости, уникальность идентификаторов и принадлежность трофеев существующим коллекциям. Неизвестная версия резервной копии отклоняется.

При удалении коллекции с трофеями выберите другую коллекцию: трофеи и даты сохранятся в ней. Последнюю непустую коллекцию можно удалить только после создания другой для переноса. Последняя пустая коллекция удаляется; перед созданием трофея приложение предложит создать коллекцию.

## Проверка и ограничения

Проверены синтаксис JavaScript и 12 автоматических сценариев. Запуск проверок без дополнительных библиотек (нужен Node.js):

```sh
node --test tests/smoke.test.cjs
```

Тесты исполняют настоящий скрипт из HTML с адаптером DOM и хранилища. Они проверяют изменения данных, отображаемую статистику, повторный запуск со старым сохранением, экспорт/импорт и отказ записи. Это не полноценный браузер: выбор файла, скачивание, нативные диалоги, реальная перезагрузка и внешний вид требуют отдельной проверки. Результаты и оставшиеся проверки — в `VERIFICATION.md`.

Сервер, облако, авторизация и зависимости для запуска приложения не используются. Переименование коллекций и следующие итерации не реализованы.
