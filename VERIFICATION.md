# Проверки итерации 1

Дата: 23 ноября 2026.

## Автоматические проверки — пройдены

Команда: `node --test tests/smoke.test.cjs`. Результат: 12 тестов, 12 пройдены, 0 ошибок.

Проверки запускают реальный скрипт из `index.html` в Node.js с небольшим адаптером интерфейса. Хранилище, системные диалоги и скачивание заменены контролируемыми моделями. Реальные пользовательские сохранения не читаются и не изменяются тестами.

1. NTrophia в интерфейсе и заголовке, сохранён прежний ключ. Старое сохранение читается без перезаписи.
2. Создание коллекции и трофеев всех четырёх редкостей, фильтрация, счётчики и прогресс 25% при одном полученном из четырёх.
3. Редактирование всех четырёх полей полученного трофея, сохранение идентификатора, даты создания и получения; отмена редактирования.
4. Получение и отмена получения, повторный запуск приложения с тем же сохранением.
5. Отмена и подтверждение удаления трофея, повторный запуск после удаления.
6. Удаление коллекции с переносом трофеев и дат, сохранение статистики; защита последней непустой коллекции.
7. Удаление последней пустой коллекции, предложение создать новую перед добавлением трофея.
8. Полный цикл экспортированного JSON → изменение данных → отмена импорта → подтверждённое восстановление → повторный запуск.
9. Отклонение неверного JSON, неправильной структуры, дубликатов идентификаторов, несуществующих коллекций, пустых/слишком длинных полей, неверных редкостей и дат, неизвестной версии. Сохранение остаётся побайтно прежним, подтверждение замены не вызывается.
10. Безопасный вывод импортированного текста и сброс неизвестных фильтров.
11. Отказ записи в хранилище не меняет трофеи, статистику или сохранение; форма редактирования остаётся открытой. Успешный импорт после восстановления записи.
12. Повреждённое старое сохранение остаётся нетронутым; изменения заблокированы до успешного восстановления через импорт.

Также проверены синтаксис JavaScript и отсутствие ошибок пробелов в изменениях Git.
